# Paper2Slides 修改计划与验收

日期：2026-11-06。依据：[三篇论文真实测试](qa/2026-11-06/README.md)。用户已授权按计划修改和验证。

| 顺序 | 优先级 | 修改 | 验收 |
|---|---|---|---|
| 1 | P0 | 合并独立图号／邻接图注，剔除正文引用；同图号候选去重 | R1图2／表2在7页；RoFormer图3／5在6／8页；V3表6在31页 |
| 2 | P0 | 真页定位＋独立边界复核、完整性失败转手动、轻微留边 | 错对象／缺列／漏数据不标成功；用户仍核验；同框多目标被拦截 |
| 3 | P1 | 长文本改为适合的宽版／双栏，图表独立页，讲稿保留细节 | 原RoFormer窄列溢出回归；不无限缩字号，不丢确认图表 |
| 4 | P1 | 统一画布／PPTX字体、行距及显式换行规则 | 同页对照，无原先的换行截断差异；不宣称跨办公软件完全一致 |
| 5 | P1 | 待确认数量与跳转、未定位状态、上传超时一次重试与导出缓存 | 用户明确知道为什么禁用；不能确认未框选整页；上传失败不重复生成 |
| 6 | P2 | 证据提炼至多2批并发，缓存和停止／失败语义不变 | 不丢并发结果，失败保留已完成批次；真实耗时与基线对比 |
| 7 | 验证 | 单元／E2E／真实模型定位／导出视觉复测，上传工作草稿 | 保留旧基线和新结果，记录额外额度；不覆盖用户原项目或审核候选1.0.2 |
