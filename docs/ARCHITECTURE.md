# Architecture

## Trust boundaries

论文、图片、补充要求均为不可信数据。系统提示与材料分离，模型不能执行工具或生成可执行HTML。应用不包含模型密钥、不访问其他App存储。所有平台访问由宿主认证。

本地预览与Anna环境通过URL中的window上下文区分；Anna连接失败时阻止运行，不悄悄切换到本地存储。生成用量来自返回的 `_meta.quotaConsumed`，无法据此推断账户余额或未上报的费用。

## PDF pipeline

PDF.js提取逐页坐标文本。栏结构分段排序并清除重复页眉页脚，页级索引每35页批次交AI判断。初步边界附近完整文本用于复核。只有用户确认且正文不超过50页、正文无低文字量警告时才能继续。正文修正再经AI核验，不能直接绕过限制。标题摘要作为额外上下文使用。

正文分块最多约10000字符，保留页码且不截断总长度。已成功的证据批次保存，失败后仅重试尚未完成部分。证据quote采用Unicode规范化与去空白后核对原文。

## Figure pipeline

识别图注候选→AI推荐与页面关联→按需对最多3个页面一批进行视觉定位→用户修正与确认→PDF页面2000px宽渲染裁图→原图进入对应幻灯片。视觉模型不支持时明确降级为手动定位。原图不重绘数值，图表可作为多个裁图片段呈现在相邻页面。

## Persistence

逻辑路径 `projects/<uuid>/` 下存放PDF、图片、快照和导出文件。KV索引指向当前及上一快照。上传新快照后通过etag切换索引，旧快照清理失败不影响当前引用，删除整个项目时再次清理。IndexDB保留未同步状态，发生冲突时用户选择加载云端或另存副本。schemaVersion不兼容则拒绝覆盖。

模型调用不无限自动重试。批次生成检查点与人工编辑分离。停止只能阻止后续调用；已提交调用可能仍计费。单页重新生成返回候选，采用前不覆盖当前编辑。

## Editor and export

SlideElement为统一数据模型：1280×720画布，text/image/rect/line，位置、大小、旋转及样式。导出坐标除以96映射到13.333×7.5英寸。文字字体px映射到pt。PPTX不使用整页截图替代可编辑文字。

客户端溢出检测是启发式，不能替代真实办公软件检查。用户可看到警告并决定返回调整或继续导出。

## Platform compatibility

本地manifest使用官方CLI支持的schema3。实测staging会将其规范化到更高schema并移除部分旧声明；以运行时可用能力和真实测试为准。staging R2 CORS允许staging域名，localhost PUT被403拒绝。不要为了本地测试而放宽平台安全配置。
