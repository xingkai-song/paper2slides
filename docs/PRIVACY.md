# 隐私与数据使用

Paper2Slides不提供独立业务服务器，不在应用代码中收集账号密码或模型API密钥。

在Anna内使用时：
- 原始论文PDF、裁剪图表、生成内容、编辑布局和导出文件保存在Anna分配的当前用户／当前应用存储空间。
- 正文识别与内容生成会把相关提取文本发送给Anna提供的模型；图表定位会发送相关页面图片。
- 编辑产生的未同步内容暂存在当前浏览器IndexedDB，用于断网恢复。
- 用户可在项目首页删除项目；部分文件删除失败会提示重试。平台底层软删除与物理清理时间由Anna管理。
- 应用不创建公开论文分享链接，不自动将用户论文提交到GitHub。

在独立本地预览中，数据只保存到当前浏览器，不自动同步到Anna。清除浏览器站点数据会删除本机预览项目与恢复内容。

模型供应商的数据处理、Anna存储、账户和额度政策以Anna平台自己的政策为准。本说明不承诺平台或供应商未公开的数据处理行为。
